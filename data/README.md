# data — то, что читает приложение

```
faq/        база знаний по ролям и тестовые обращения (Стася)
schedule/   .xls расписаний по институтам (nyonless)
```

Приложение обращается сюда через `DATA_DIR`: локально это `./var`, в контейнере `/data`.
Файлы отсюда копируются в том при запуске.

Черновики и выписки сюда не кладём — им место в `team/<кто>/materials/`.
