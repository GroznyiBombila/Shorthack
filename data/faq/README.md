# База знаний

Зона Стаси. Четыре файла, все в UTF-8:

```
faq_applicant.json   для поступающих
faq_student.json     для студентов
faq_teacher.json     для преподавателей
samples.json         тестовые обращения живым языком
```

Формат записи и правила — в [постановке](../../team/stasya/task/03-stasya-faq-data.md).
Самое важное поле — `keywords`: по нему помощник решает, открывать ли раздел вообще.
