Донор: `C:\Users\alexa\VSCode\OsadaSupportBot` (Telegram-бот поддержки OSADA VPN на Groq).
Берём отлаженное, выкидываем всё, что не видно в демо.

## Берём (порт с адаптацией)

| Из донора | Что это | Куда у нас | Зачем |

## Не берём

| Что | Почему |
|---|---|
| `bot.py`, `ui.py`, aiogram-слой, баннеры | Канал демо — веб, не Telegram |
| Консоль оператора (`escalation.py`, ~900 строк UI) | Не влезет в 6 часов и не нужно для оценки |
| Цепочка фолбэка моделей, разбор 429/413 Groq, `models.py` | У Yandex Cloud одна модель и другой режим лимитов |
| PostgreSQL/asyncpg, пул, ретеншн | SQLite достаточно для прототипа |
| Подписки, `get_subscription_status`, бан-лист | Вне условия задачи |

## Что меняется принципиально

- **Провайдер**: Groq SDK → HTTP-вызовы Yandex Cloud Foundation Models с `Authorization: Api-Key`.
- **Режим работы**: донор — диалоговый Q&A-бот; у нас — **однопроходный анализатор обращения**, отдающий структуру (JSON), а не реплику.
- **Выход**: вместо текста ответа — структурированная карточка: суть, категория, срочность, недостающие данные, список вопросов из обращения, следующий шаг и готовое действие.
