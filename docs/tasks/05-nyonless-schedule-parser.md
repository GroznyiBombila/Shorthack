# Задача 5 — разбор файлов расписания

**Исполнитель:** nyonless · **Срок:** T+4:00, **после** задачи 1 (авторизация и почта) ·
**Зависимостей в коде нет** — модуль самостоятельный.

Эту постановку можно целиком скопировать в чат с LLM.

---

## Контекст

Делаем ИИ-помощника поддержки МИСИС. Авторизованный студент указывает свой институт и группу,
и получает кнопку «Расписание на сегодня» — помощник отвечает списком пар. Преподаватель так
же получает свои занятия по фамилии.

**Языковая модель здесь не участвует вообще.** Расписание — это таблица, а не текст: разбор
и выборка делаются чистым алгоритмом. Модель на такой задаче только добавила бы задержку,
стоимость и шанс придумать несуществующую пару. Это важный тезис нашей защиты, так что
модуль должен быть детерминированным и покрытым тестами.

## Что на входе

Файлы `.xls` (старый бинарный формат, **не** `.xlsx`), по одному на институт.
Пример лежит в `data/schedule/itkn-110926.xls`.

**Полный разбор формата — в [docs/DATA-schedule.md](../DATA-schedule.md).** Прочитай его
целиком перед началом: там расписаны листы, шапка, раскладка колонок по группам и подгруппам,
структура «две строки на пару» и ловушка с латинской буквой в номере аудитории. Это сэкономит
тебе час на реверс-инжиниринге.

## Файл 1: `app/schedule_parser.py`

```python
def parse_schedule_file(path: str, institute: str) -> dict:
    """Разбирает .xls в структуру, описанную в docs/DATA-schedule.md.
    Возвращает {'institute', 'source_file', 'parsed_at', 'groups': {...}}."""

def parse_lesson_cell(subject_cell: str, room_cell: str) -> dict | None:
    """'Математика (Практические)\\nКим-Тян Л. Р.' + 'Л-629' →
    {'subject', 'kind', 'teacher', 'room', 'subgroup_override'}.
    None, если ячейка пустая."""

def normalize_room(room: str) -> str:
    """Приводит номер аудитории к единому виду: латинские A E K M H O P C T X
    заменяются на кириллические, схлопываются пробелы."""
```

### Требования к разбору

- `kind`: `Лекционные` → `lecture`, `Практические` → `practice`, `Лабораторные` → `lab`,
  всё прочее → `other`.
- Преподавателя может не быть (физкультура, иностранный язык) — это норма, поле `null`,
  не ошибка разбора.
- Префикс `1, 2 п.г.` в начале предмета означает занятие сразу для обеих подгрупп:
  вырезать префикс из названия и выставить `subgroup: null`.
- День недели, номер пары и время указаны только в первой строке блока — протягивать вниз.
- Первая строка пары — верхняя неделя, вторая — нижняя.
- Пустая ячейка — окно, а не ошибка. Пустых ячеек в файле большинство.
- Файл с неожиданной структурой не должен ронять процесс: логируем, что не разобрали,
  и возвращаем то, что разобрали.

### Требования к выборке

- Воскресенье и дни без пар возвращают пустой список — это валидный ответ, не ошибка.
- В выдаче каждой пары: номер, время начала и конца, предмет, тип, преподаватель, аудитория.
- Поиск по преподавателю сопоставляет фамилии нестрого: `'Ким-Тян Л. Р.'` и `'ким-тян л.р.'`
  должны находиться одинаково.
- Разбор файлов делается один раз при старте, не на каждый запрос.

## Тесты: `tests/test_schedule.py`

На приложенном файле `itkn-110926.xls`:

1. Разбираются все 6 листов, группы найдены, их больше десяти.
2. У группы `ББИ-26-6-1` в понедельник на второй паре — «Введение в специальность»,
   тип `lab`, аудитория `Л-812-УВЦ`.
3. У той же группы вторая строка той же пары (нижняя неделя) — «Математика», тип `practice`.
4. `parse_lesson_cell` вырезает префикс `1, 2 п.г.` и выставляет `subgroup: null`.
5. Занятие без преподавателя (физкультура) разбирается, `teacher` равен `null`.
6. `normalize_room` приводит `K-527` с латинской `K` к кириллической.
7. `week_parity` на двух соседних неделях даёт разные значения.
8. `for_group` на воскресенье возвращает пустой список без исключения.
9. `for_teacher('Ким-Тян Л. Р.', ...)` находит пары, регистр не мешает.

## Критерии приёмки

- `pytest tests/test_schedule.py -q` — зелёный.
- Разбор всего файла занимает меньше двух секунд.
- Модуль не ходит в сеть и не использует языковую модель.
- Добавленные зависимости: только `xlrd`, вписать в `requirements.txt`.

## Чего НЕ делать

Не пиши HTTP-эндпоинты — подключу я. Не привязывайся к конкретным названиям групп или
институтов: файлов будет несколько, коды институтов разные. Не подключай языковую модель
ни для разбора, ни для поиска — вся суть задачи в том, что здесь она не нужна.
