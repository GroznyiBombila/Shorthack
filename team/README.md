# Папки участников

У каждого своя папка. Внутри — всё, что нужно для работы, и всё, что участник публикует.
Ничего не раскидываем по репозиторию «где придётся».

```
team/<кто>/
  README.md     маршрутный лист: что делаешь, что читать, куда класть
  task/         постановка задачи — читать первым делом
  materials/    всё некодовое, что ты публикуешь: макеты, скриншоты, слайды, черновики, заметки
```

## Одно исключение

Код и данные, которые читает приложение, лежат по общим фиксированным путям —
`app/`, `web/`, `data/`. Иначе оно просто не запустится: пути зашиты в импортах и в
конфигурации. В маршрутном листе каждого написано, какие именно файлы там его.

Всё остальное — в своей папке.
