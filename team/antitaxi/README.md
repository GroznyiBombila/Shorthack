# antitaxi — интерфейс

Ты делаешь весь фронт: экраны, вёрстку, поведение. Без сборки и без CDN —
чистые HTML, CSS и JS, которые открываются файлом.

## Что прочитать перед началом

- свою постановку — целиком, там перечислены все семь экранов;
- [контракты API](../../docs/API.md) — какие запросы уходят и что приходит в ответ.
  Контракты уже заморожены, можно верстать под них до готовности бэкенда.

## Работай на моках

В постановке описан режим `window.USE_MOCK = true`: ответы берутся из объекта с примерами,
бэкенд не нужен. Разрабатывай так — и **не ломай этот режим потом**, он нужен как страховка
на защите, если сеть подведёт.

## Правила

- Ветка `feat/ui-...`, один PR.
- Контракты запросов не меняем в одиночку: сначала договариваемся, потом правим `docs/API.md`.
- Никаких внешних ссылок на шрифты и библиотеки: на защите может не быть интернета.
