# Формат файла расписания (разобран на `itkn-110926.xls`)

Исходник — `.xls` (старый бинарный формат BIFF, **не** `.xlsx`). Читается библиотекой `xlrd`.
Один файл = один институт. Имя файла: `{код института}-{ддммгг}.xls`, например `itkn-110926.xls`.

## Листы

Каждый лист — курс:

```
['1 курс', '2 курс', '3 курс', '4 курс', '1 курс магистратура|СВО', '2 курс магистратура|СВО']
```

Названия листов разбирать не надо жёстко: номер курса — первое число в имени листа,
магистратура определяется вхождением слова «магистратура».

## Шапка

| Строка | Содержимое |
|---|---|
| 0 | `Дата` \| `Номер` \| `Время` \| дальше названия групп |
| 1 | пусто \| пусто \| пусто \| дальше номера подгрупп |

**Одна группа занимает ровно 4 колонки.** Название группы записано в объединённой ячейке
(строки 0–1, четыре колонки). Внутри группы:

| Смещение от начала группы | Что в колонке |
|---|---|
| +0 | предмет, подгруппа 1 |
| +1 | аудитория, подгруппа 1 |
| +2 | предмет, подгруппа 2 |
| +3 | аудитория, подгруппа 2 |

Группа `i` (с нуля) начинается в колонке `3 + 4*i`. В строке 1 стоят `1.0` и `2.0` —
номера подгрупп, приходят как `float`.

## Тело

Строки 2..99. Ровно **7 дней по 14 строк**:

```
строки 2..15   Понедельник
строки 16..29  Вторник
строки 30..43  Среда
строки 44..57  Четверг
строки 58..71  Пятница
строки 72..85  Суббота
строки 86..99  Воскресенье
```

День недели написан только в первой строке дня (колонка 0), дальше пусто — значение нужно
протягивать вниз. То же с номером пары и временем: они стоят только в первой строке пары.

**Каждая пара занимает две строки подряд:**

- первая строка — **верхняя неделя** (числитель);
- вторая строка — **нижняя неделя** (знаменатель).

Если обе строки одинаковые — пара идёт каждую неделю. Если заполнена только одна —
занятие раз в две недели. Пустые обе — окно.

### Пары и время

| № | Время |
|---|---|
| 1 | 09:00 – 10:35 |
| 2 | 10:50 – 12:25 |
| 3 | 12:40 – 14:15 |
| 4 | 14:30 – 16:05 |
| 5 | 16:20 – 17:55 |
| 6 | 18:00 – 19:25 |
| 7 | 19:35 – 21:00 |

Время в ячейке лежит строкой `'09:00:00 - 10:35:00'`. Опираться лучше на номер пары, а
время брать из ячейки.

## Формат ячейки предмета

```
Математика (Практические)
Ким-Тян Л. Р.
```

То есть: `Название предмета (Тип занятия)` + перевод строки + `Преподаватель`.

- Тип занятия: `Лекционные`, `Практические`, `Лабораторные`.
- **Преподавателя может не быть** — например, «Иностранный язык (Практические)» и
  «Физическая культура и спорт (Практические)» идут без фамилии. Это норма, не ошибка.
- Встречается префикс `1, 2 п.г.` — занятие идёт для обеих подгрупп сразу:
  `'1, 2 п.г. Введение в специальность (Лабораторные)\nНеворошкин В. А.'`

## Аудитория

Значения разнородные: `Л-812-УВЦ`, `К-214`, `Б-3`, `Каф. ИЯКТ`,
`Спортивный комплекс Горного института`. Свободный текст, никакой схемы не навязывать.

> **Ловушка в данных.** В файле встречается `K-527` с **латинской** `K` вместо кириллической
> `К` — визуально неотличимо. При нормализации и поиске по аудитории латинские `A E K M H O P C T X`
> приводить к кириллическим, иначе одна и та же аудитория будет двумя разными.

## Целевая структура после разбора

```json
{
  "institute": "ИТКН",
  "source_file": "itkn-110926.xls",
  "parsed_at": "2026-09-12T11:40:00Z",
  "groups": {
    "ББИ-26-6-1": {
      "course": 1,
      "level": "bachelor",
      "lessons": [
        {
          "day_index": 0,
          "day": "Понедельник",
          "pair": 2,
          "time_start": "10:50",
          "time_end": "12:25",
          "week": "upper",
          "subgroup": null,
          "subject": "Введение в специальность",
          "kind": "lab",
          "teacher": "Неворошкин В. А.",
          "room": "Л-812-УВЦ"
        }
      ]
    }
  }
}
```

- `kind`: `lecture` | `practice` | `lab` | `other`
- `subgroup`: `1`, `2` или `null`, если занятие для обеих подгрупп (префикс `1, 2 п.г.`)
- `week`: `upper` | `lower`
- `day_index`: 0 — понедельник, 6 — воскресенье

## Открытый вопрос: какая неделя сейчас

В файле нет календарных дат — только дни недели. Чтобы ответить «какое расписание сегодня»,
нужно знать чётность текущей недели.

Решение: переменная окружения `SEMESTER_START` (дата первого понедельника семестра), дальше
`week = "upper" if ((date - semester_start).days // 7) % 2 == 0 else "lower"`. Значение
подберём по реальному расписанию перед демо: берём известный день, смотрим, что должно быть,
и сверяем.
