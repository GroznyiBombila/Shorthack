## Главное про формат

Помощник сначала видит **только заголовки и ключевые слова**, и уже по ним решает, какой
раздел открыть. Поэтому `keywords` — самое важное поле: со слабыми ключевыми словами раздел
не найдётся, каким бы хорошим ни было содержание. Пиши разговорные формулировки —
«взять академ», «когда придёт стипуха», — а не только официальные названия разделов.

## Волнами

Всю базу за хакатон не собрать, и это нормально. Работа разбита на волны: сначала вширь,
потом вглубь. После любой волны база рабочая.

| Волна | Что | Когда |
|---|---|---|
| 0. Каркас — 9 записей | по три самых частых темы на роль | T+1:00 |
| 1. Вширь — +15 | по записи на каждую категорию | T+2:00 |
| 2. Вглубь — +15 | подробности частых тем | T+3:00 |
| 3. Остальное | редкие реальные вопросы | T+4:00 |

**Коммить и пушить после каждой волны.** Я подключаю данные сразу, как они появляются,
а не в конце.

## Правила

- Ветка `feat/data-faq`.
- JSON должен быть валидным и в UTF-8 — проверяй любым онлайн-валидатором перед коммитом.
- Ссылки обязаны открываться: помощник показывает их пользователю, битая ссылка на защите — провал.
- **Фактов не выдумывать.** Нет информации на сайте — пропусти запись. Выдуманное помощник
  выдаст пользователю как правду.
- Расписание занятий собирать не нужно, оно берётся из файлов автоматически.
