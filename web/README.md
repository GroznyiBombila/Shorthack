# web — интерфейс

Зона antitaxi. Чистые HTML, CSS и JS: без сборки, без CDN, без внешних шрифтов —
на защите может не быть интернета.

```
index.html
style.css
app.js
```

Режим `window.USE_MOCK = true` работает без бэкенда и должен продолжать работать
после подключения настоящего API — это страховка на демо.
